# 🏰 Territory Conquest Mod — プレイヤーガイド

> このガイドは、Minecraftを遊んだことがある人向けに書かれています。  
> プログラムの知識は一切不要です。

---

## 📖 このMODでできること

このMODは、**マルチプレイヤーで「国」を作って覇権を争う**サバイバルMODです。

- 旗を置いてチャンク（土地）を自分の領土にできます
- 領土にはゴールド（G）の国庫があり、鉄やダイヤなどのアイテムを売ってGを稼ぎます
- 旗は国庫のGで購入します
- 領土が広いほど毎日維持費がかかります
- 放置すると領土が「腐敗」し、敵が湧きます
- 旗を設置するとき、まれに呪われた土地に踏み込んでモンスターが現れることも！

---

## 🚀 はじめかた（初回ログイン時）

ワールドに初めてログインすると、自動的にあなたのスポーン地点が**「聖域チャンク」**として登録されます。  
聖域チャンクはあなたの本拠地で、**誰にも奪われません**。

> [!IMPORTANT]
> スポーン地点（聖域チャンク）には必ず**コアブロック**が設置されています。  
> これがあなたの国の中心です。壊さないように！

---

## 🏗️ コアブロックとサブコア

### コアブロック（本拠地の中心）

スポーン地点に置かれている輝く特別なブロックです。  
右クリックすると**国の管理画面**が開きます。

管理画面でできること：

- 国庫のゴールド（G）残高の確認
- **総合取引所**（アイテムの売買）を開く
- コアの強化（防衛力アップ）

### サブコア（前線基地）

自分の領土の中に追加で置けるブロックです。  
サブコアを置くことで、その周辺チャンクの**防衛力が上がります**。

> [!NOTE]
> サブコアは**屋外かつ空が見える場所**にしか置けません。洞窟の中や屋根の下はNGです。

---

## 🚩 開拓の旗（領土を広げる方法）

領土を広げるには**「開拓の旗」**を使います。

### 旗の入手方法

**総合取引所**の「購入」タブで **200G** と交換できます。

### 旗の置き方（ルール）

| 条件                  | 詳細                                           |
| --------------------- | ---------------------------------------------- |
| ✅ 中立チャンク       | 誰も領有していないチャンクにしか置けない       |
| ✅ 自領土に隣接       | 今の自分の領土に隣接したチャンクにしか置けない |
| ❌ 他プレイヤーの領土 | 他の人の旗があるチャンクには置けない           |

旗を置くと「開拓の旗を○○に領有しました！」というメッセージが出ます。

### ⚠️ 呪われた土地（5%の危険）

旗を中立チャンクに置くとき、**10回に1回ほど（5%）**の確率で「呪われた土地」に当たります！  
すると…

- 不吉な呪いの音が鳴り響く
- **鉄装備の強化ゾンビ・ノックバック弓のスケルトン**が2〜3体スポーン！
- ただし旗の設置はそのまま成功し、チャンクは領有されます

> [!TIP]
> 旗を置くときはいつでも武装しておきましょう！特に序盤の弓矢は危険です。

### 旗の光源機能

旗は設置すると**松明と同じ明るさ（光源レベル15）**で周囲を照らします。  
ダンジョンや洞窟探索での仮設ベースとしても使えます。

---

## 💰 ゴールド（国庫）のしくみ

国庫のG（ゴールド）は**あなたの国のお金**です。  
個人のインベントリには入らず、コアブロックに紐づいた「口座」に蓄積されます。

Gの使いみち：

- 開拓の旗の購入（200G/個）
- コアの強化（強化費用はコア画面参照）
- 毎日の領土維持費の支払い（自動）

---

## 🏪 総合取引所（アイテムの売買）

コアまたはサブコアを右クリック→「**総合取引所 (アイテム売買)**」ボタンで開きます。

### タブ切り替え

| タブ                 | 内容                    |
| -------------------- | ----------------------- |
| 買取（アイテム売却） | アイテムを売ってGを得る |
| 購入（アイテム購入） | Gを使ってアイテムを買う |

### 売却の手順

1. 左のリストから売りたいアイテムを選ぶ
2. 右に「現在のレート」「手持ちの数量」「累計売却数」が表示される
3. 下のスライダーで売りたい数を調整する（最大1スタック=64個まで）
4. 「取引する」ボタンを押す → Gが国庫に入る

---

## 📉 価格インフレシステム（売れば売るほど安くなる）

同じアイテムを大量に売り続けると、**段階的にレートが下がります**。  
現実の経済のようなシステムです。

### 鉄インゴット

| レベル | 累計売却数                   | レート        |
| ------ | ---------------------------- | ------------- |
| Lv1    | 0〜5スタック（320個まで）    | 1個 → **50G** |
| Lv2    | 6〜30スタック（321〜1920個） | 1個 → **10G** |
| Lv3    | 31スタック以上（1921個〜）   | 16個 → **5G** |

### 金インゴット

| レベル | 累計売却数     | レート         |
| ------ | -------------- | -------------- |
| Lv1    | 0〜5スタック   | 1個 → **150G** |
| Lv2    | 6〜25スタック  | 1個 → **30G**  |
| Lv3    | 26スタック以上 | 4個 → **5G**   |

### エメラルド

| レベル | 累計売却数     | レート         |
| ------ | -------------- | -------------- |
| Lv1    | 0〜10スタック  | 1個 → **300G** |
| Lv2    | 11スタック以上 | 1個 → **50G**  |

### 固定レートのアイテム

| アイテム             | レート                         |
| -------------------- | ------------------------------ |
| ダイヤモンド         | 1個 → **1,500G**（常時固定）   |
| ネザライトインゴット | 1個 → **15,000G**（常時固定）  |
| ネザースター         | 1個 → **100,000G**（常時固定） |
| 本                   | 1個 → **10G**（常時固定）      |
| 干草の俵             | 1個 → **5G**（常時固定）       |

> [!TIP]
> 序盤は鉄を大量生産して売りまくるのが一番手っ取り早いですが、  
> 無限鉄を作ると段階的にレートが落ちていきます。  
> 国が発展したらダイヤやネザライトに切り替えましょう！

## ⚔️ 維持費と領土の腐敗

### 毎朝の維持費

**マイクラの1日が明けるごとに（毎朝）**、国庫から自動的に維持費が引かれます。

```
維持費 = 領有チャンク数 × 2G / 日
```

**例：** 30チャンク保有 → 毎朝 **60G** が自動で引かれます

### 国庫が尽きると…（領土の腐敗）

維持費を払えなかった朝に発生します：

1. 📍 メインコアから**最も遠い場所にある旗**が自動的に破壊されます
2. 💀 その場所に**強化ゾンビ・スケルトン が3〜6体**スポーンします
3. 🔔 チャットに「領土が腐敗しました！」という警告が届きます

> [!WARNING]
> 国庫が常に空の状態が続くと、毎朝少しずつ領土が剥ぎ取られていきます。  
> アイテムを定期的に売って、常に黒字を維持しましょう！

## 🗺️ 攻略のヒント

### 序盤（開始〜国庫1,000G）

- スポーン聖域でまず鉄を集める
- 鉄を総合取引所で売って旗を購入（200G）
- 隣接するチャンクへ少しずつ領土を広げる
- **あまり広げすぎると維持費が上がる**ので、使える分だけ確保！

### 中盤（領土10〜30チャンク）

- 金やエメラルドを採掘して高単価で売る
- サブコアを要所に設置して防衛力を上げる
- 維持費の計算式を意識しながら計画的に拡張する

### 後半（豊かな国に）

- ダイヤモンドやネザライトで大量のGを稼ぐ
- 他プレイヤーの旗を壊して領土を奪う戦争も可能
- ネザースターを売れば**一発で10万G**の大収入！

## ❓ よくある質問

**Q. 旗が置けない！**  
A. 自分の現在の領土に**隣接していない**チャンクには置けません。  
まず隣のチャンクを順番に開拓してから、さらに広げましょう。

**Q. 突然モンスターが湧いた！**  
A. 旗を置いたとき5%の確率で「呪われた土地」イベントが発生します。  
これはランダムで防ぐことはできませんが、武装していれば問題ありません。

**Q. 旗を壊したらどうなる？**  
A. そのチャンクの領有が解除され、中立チャンクに戻ります。  
誰か他のプレイヤーに旗を壊されると、領土が消滅してしまいます！

**Q. 国庫のGが減っていく…**  
A. 毎朝「領有チャンク数 × 2G」が維持費として自動で引かれています。  
アイテムを売ってGを補充するか、いくつか旗を撤去して維持費を減らしましょう。

**Q. サブコアとコアブロックの違いは？**  
A. コアブロックはスポーン地点にある唯一の本拠地です。破壊されると大打撃です。  
サブコアは自分の領土に追加で置ける前線基地で、防衛強化のために使います。
